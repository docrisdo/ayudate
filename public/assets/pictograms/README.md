# Pictogramas AYÚDATE

Este set se diseñó para apoyar comprensión cognitiva y comunicación en la interfaz.

Reglas de uso:
- Mostrar siempre el pictograma junto a una etiqueta visible de texto.
- No usar el pictograma como único medio para comunicar una acción importante.
- Mantener el mismo pictograma para la misma función en toda la app.
- Usar los SVG cuando sea posible; son escalables y conservan nitidez.
- Si el pictograma es redundante junto a texto visible dentro de un botón, marcar el SVG/imagen como decorativo para lector de pantalla (`aria-hidden="true"` o `alt=""`) y dejar que el botón tome su nombre del texto visible.
- Si el pictograma transmite información que no aparece en texto, proporcionar un nombre/alternativa accesible.
- No cambiar formas ni significados; solo tamaño y, si fuera necesario, color manteniendo contraste.
