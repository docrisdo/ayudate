# AYÚDATE — Assets finales

Este paquete contiene SOLO la selección final organizada para la implementación. No incluye las versiones anteriores descartadas.

## Para Codex
Copia la carpeta `public/assets` directamente dentro del proyecto. Las rutas del archivo `asset-manifest.json` ya están pensadas para un proyecto web servido desde `public`.

### Reglas recomendadas
- Usa los PNG proporcionados directamente.
- No recrees las imágenes con CSS, SVG improvisado, emojis o placeholders.
- Las capturas de `references/screens` son la fuente de verdad visual para layout, tamaño y posición.
- Los SVG de `icons/svg` sí pueden usarse como iconos escalables.

## Organización
- `branding/`: logo correcto de AYÚDATE.
- `banners/`: banners finales aprobados.
- `illustrations/`: recursos visuales grandes para Inicio, listas, ruta y bienvenida.
- `products/`: productos realistas individuales aprobados.
- `search-products/`: miniaturas específicas de la pantalla Buscar producto.
- `icons/`: iconos PNG y SVG.
- `references/screens/`: las 10 pantallas de referencia.
